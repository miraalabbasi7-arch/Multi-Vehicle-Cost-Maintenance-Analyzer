# Multi-Vehicle Cost & Maintenance Analyzer

## Project Overview
The **Multi-Vehicle Cost & Maintenance Analyzer** is a C++ console-based university semester project developed as part of the Computer Programming course at Bahria University.
The project aims to help vehicle owners monitor and analyze the costs and maintenance requirements of multiple vehicles. It provides features for tracking fuel consumption, calculating fuel efficiency, recording maintenance activities, analyzing vehicle expenses, and identifying upcoming maintenance needs.
The system is designed to turn vehicle-related records into useful information through calculations, comparisons, and graphical reports.

## Key Features
- **Vehicle Profile Management:** Register and manage multiple cars and motorcycles.
- **Fuel Tracking:** Record fuel purchases and calculate fuel expenses.
- **Fuel Efficiency Analysis:** Calculate and compare vehicle fuel efficiency in km/L.
- **Maintenance Due Analyzer:** Track maintenance records and identify upcoming or overdue services.
- **Expense Analysis:** Calculate and compare fuel, maintenance, and total vehicle expenses.
- **Graphical Reports:** Display comparisons and spending trends through console-based graphs.
- **File Handling:** Save and load records to preserve data between sessions.

## How to Run the Project
1. Clone or download this repository.
2. Open the solution file (`.slnx`) in Microsoft Visual Studio.
3. Allow Visual Studio to load the project.
4. Select the desired build configuration (Debug or Release).
5. Build the project using **Build Solution**.
6. Run the application using **Ctrl + F5**.
