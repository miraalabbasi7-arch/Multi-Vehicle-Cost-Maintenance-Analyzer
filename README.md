\# Vehicle Management System



\## Project Overview



The \*\*Vehicle Management System\*\* is a C++ console-based university semester project developed as part of the Computer Programming course at Bahria University.



The project aims to provide a structured system for managing vehicle-related information and operations. Further details about its functionalities and implementation will be added as development progresses.

\## How to Run the Project



1\. Clone or download this repository.

2\. Open the solution file (`.slnx`) in Microsoft Visual Studio.

3\. Allow Visual Studio to load the project.

4\. Select the desired build configuration (Debug or Release).

5\. Build the project using \*\*Build Solution\*\*.

6\. Run the application using \*\*Ctrl + F5\*\*.
